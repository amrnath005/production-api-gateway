# PostgreSQL & pgAdmin Management Guide

## Database Architecture
- **Database Name**: `api_gateway`
- **User**: `gateway`
- **Password**: `gateway_password`
- **Host**: `postgres:5432`

## pgAdmin Management
Access pgAdmin UI at `http://localhost:5050` (Login: `admin@admin.com` / `admin`). The `API Gateway Postgres` server connection is automatically pre-provisioned via `pgadmin/servers.json`.
